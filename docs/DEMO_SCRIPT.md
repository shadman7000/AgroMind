# AgroMind product walkthrough (5–7 minutes)

## Setup
1. Run `npm run dev`.
2. Open http://localhost:3000.
3. Use a full-width browser window.

## Talk track

1. **Login (30s)**  
   Brand: AgroMind. Continue with Google. Note the simulated-sensor badge while hardware is not connected.

2. **Today’s jobs (60s)**  
   Job cards for the day. Story: Plot B soil looks thirsty. Move to the plan or stay on the shortlist.

3. **Field + Soil (60–75s)**  
   **Field** — plot map + moisture gauges. **Soil** — nutrition list (N/P/K, moisture, pH) with plain-language notes.

4. **Weather (45s)**  
   Forecast + disease probability in plain language (“Medium chance if nights stay humid”).

5. **Costing (45s)**  
   Market prices. Adjust the profit calculator and show the estimate update.

6. **Plan (90s)**  
   Coordinator summary. Open **Why we suggest this** on one action. **Accept** one, **Reject** another — status updates.

7. **What-if (60s)**  
   Toggle **If rain tomorrow**. Recommendations morph (skip watering, delay fertilizer, clear drainage).

8. **Close (20s)**  
   Recap the loop: sense → plan → decide → simulate alternatives.
